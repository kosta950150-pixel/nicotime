# NICOTIME — Telegram Mini App (первая рабочая версия)

Это **внутренняя админ-система учёта ассортимента**, а не публичный каталог и не система оформления заказов.

## Что реализовано
- Telegram-бот с кнопкой открытия Mini App (`/start`).
- Проверка подлинности Telegram Web App `initData` на сервере.
- Дополнительный пароль администратора и проверка Telegram ID.
- SQLite-база: категории, товары, варианты, остатки, скидка и признак новинки.
- Создание/редактирование/удаление товаров и вариантов.
- Фильтр категорий и поиск.
- Автообновление данных в панели каждые 12 секунд.
- Адаптивный интерфейс для телефонов и компьютеров.

## Запуск локально для проверки интерфейса
Нужен Python 3.10+.

1. Распакуйте архив и откройте папку проекта.
2. Установите зависимости:
   `python -m venv .venv`
   - Windows: `.venv\\Scripts\\activate`
   - macOS/Linux: `source .venv/bin/activate`
   `pip install -r requirements.txt`
3. Скопируйте `.env.example` в `.env`.
4. Заполните `ADMIN_TELEGRAM_ID`, `ADMIN_PASSWORD`, `APP_SECRET`.
5. Для локального просмотра в обычном браузере временно поставьте `DEV_MODE=true`.
6. Запустите API: `uvicorn app:app --reload`
7. Откройте `http://127.0.0.1:8000`.

В режиме локальной разработки Telegram ID берётся из `ADMIN_TELEGRAM_ID`; это только для локального теста. Не оставляйте `DEV_MODE=true` на публичном сервере.

## Подключение Telegram
1. Создайте бота через `@BotFather` и получите токен.
2. Разместите приложение на сервере с публичным HTTPS-доменом.
3. Укажите в `.env` `BOT_TOKEN`, `WEBAPP_URL`, `ADMIN_TELEGRAM_ID`, `ADMIN_PASSWORD`, `APP_SECRET`.
4. Установите `DEV_MODE=false`.
5. В `@BotFather` настройте домен Mini App через `/setdomain` (если требуется для выбранного способа запуска).
6. Запустите API: `uvicorn app:app --host 0.0.0.0 --port 8000`.
7. В отдельном процессе запустите бота: `python bot.py`.
8. Откройте бота в Telegram и отправьте `/start`.

## Важно для production
- Используйте только HTTPS.
- Сгенерируйте длинный случайный `APP_SECRET` и надёжный пароль.
- Не публикуйте `.env` и не отправляйте токен бота посторонним.
- Ограничьте доступ к серверу, настройте резервное копирование папки `data/`.
- Для реального запуска настройте HTTPS reverse proxy (например, Caddy или Nginx), автозапуск процессов (systemd/Docker) и мониторинг.
- SQLite подходит для первой небольшой версии; при росте нагрузки можно перейти на PostgreSQL.
- Внутренняя система не реализует оформление заказов, оплату, доставку или публичную демонстрацию никотинсодержащей продукции. Публичные функции следует отдельно проверить на соответствие законодательству РФ.

## Структура
- `app.py` — API и база данных.
- `bot.py` — Telegram-бот.
- `static/index.html` — интерфейс Mini App.
- `.env.example` — пример настроек.
